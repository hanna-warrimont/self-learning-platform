# Self Learning Platform

Persönliche Lernumgebung: lernen durch eigenes Coden, ohne Videos. Jede Lektion endet mit einer Aufgabe, die automatisch geprüft wird.

- **Kurs 1:** System Design (Fortgeschritten) – Kursprojekt „TicketRush“
- **Kurs 2 (geplant):** FinTech Stack
- **Stack:** .NET · Nuxt · PostgreSQL · Redis · RabbitMQ · Docker

## Struktur
```
docs/       Konzept, Entscheidungen, Kursgliederungen
modules/    (folgt) Kursmodule mit Theorie, Aufgabe, Tests, Hinweisen
```
